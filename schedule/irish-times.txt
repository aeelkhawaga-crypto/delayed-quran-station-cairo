# at each of these times, then resumes the delayed stream.
#
# Formats (one event per line, # starts a comment):
#   HH:MM              daily, interpreted in Europe/Dublin local time
#   Mon 05:30          weekly, on the given day (Mon Tue Wed Thu Fri Sat Sun)
#   2026-09-15 18:23   one-off, exact date
#
# Times shift with Irish daylight saving automatically.
